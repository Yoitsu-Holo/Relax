# Buddy System 性能测试报告

**测试日期：** 2026-01-10
**测试系统：** Linux 6.18.3-zen1-1-zen
**编译器：** GCC with -O2 优化
**总操作数：** 每种块大小 10,000,000 次分配/释放对

## 执行摘要

Buddy System 分配器在大多数块大小上展现出**优异的性能**，相比标准库分配器（malloc/free 和 new/delete），在中大型分配（8KiB+）上表现尤为突出。

### 核心发现

- **总体胜率：** Buddy 分配器在 **7 个测试用例中赢得 6 个**
- **最佳性能：** 32KiB 块比 new/delete 快 1.69 倍（68.53% 提升）
- **最优范围：** 8KiB - 256KiB 块显示持续的 13-56% 性能提升
- **小块开销：** 4KiB 块由于位图开销表现慢 8-18%

### 1. 小块分配 (4 KiB) - Order 0

**测试结果：** 标准库分配器获胜

```
Buddy 分配器:           108.24 ns/分配  (18.48M 次/秒)
标准 malloc/free:        99.25 ns/分配  (20.15M 次/秒)  ✓ 胜出
标准 new/delete:         88.95 ns/分配  (22.48M 次/秒)  ✓ 胜出
```

**性能对比：**
- vs malloc/free: **0.92x** (慢 8.31%)
- vs new/delete: **0.82x** (慢 17.82%)

**分析：**
- 在最小分配大小下，位图管理开销变得显著
- 标准分配器针对小型、高频分配进行了优化
- 权衡：Buddy 提供更好的碎片控制，但速度有所损失

## 技术分析

### Buddy 为何在 8KiB+ 获胜

1. **O(1) 分配：** 二级位图实现常数时间空闲块查找
2. **最小元数据：** 无需按分配头部，仅紧凑的位图条目
3. **缓存效率：** 连续的 16MiB 内存池，可预测的访问模式
4. **零碎片：** 2 的幂次 buddy 合并消除外部碎片
5. **FORCE_INLINE：** 关键路径函数内联，零调用开销

### Buddy 为何在 4KiB 表现欠佳

1. **位图开销：** 管理 4096 个块需要更多位操作
2. **粒度成本：** Order-0 操作触及最多位图层级
3. **分配密度：** 标准分配器针对高密度小块优化
4. **缓存行竞争：** 更频繁的位图更新 = 更多缓存未命中

### 标准库观察

- **malloc/free：** 对于 8KiB+ 一致慢于 Buddy（系统调用开销）
- **new/delete：** 在 32KiB 显示显著退化（C++ 异常安全开销）
- **两者：** 在超大块上性能趋于一致（可能使用 mmap）

## 使用建议

### 何时使用 Buddy System

✅ **推荐使用：**
- 需要可预测分配时间的实时系统
- 具有 8KiB - 256KiB 分配模式的应用
- 有界内存大小需求的内存池
- 对内存碎片敏感的系统
- 高吞吐量网络/存储缓冲区

❌ **不推荐使用：**
- 高频率的微小分配（<4KiB）
- 无界内存需求（Buddy 池固定为 16MiB）
- 跨越多个数量级的混合分配大小

### 优化机会

**已实现：**
- ✓ 二级位图实现 O(1) 搜索
- ✓ 关键路径上的 FORCE_INLINE
- ✓ Switch-case fallthrough 批量位图更新
- ✓ constexpr 编译期掩码生成

**潜在改进：**
- [ ] 位图操作的 SIMD 指令（AVX2/AVX-512）
- [ ] 可预测访问模式的预取提示
- [ ] 无锁多线程的每 CPU 分配池
- [ ] 基于分配模式的自适应批次大小

## 测试方法论

### 测试环境
- **平台：** x86_64 Linux
- **内核：** 6.18.3-zen1-1-zen (低延迟)
- **编译器：** GCC -O2 (平衡优化)
- **计时：** std::chrono::high_resolution_clock (纳秒精度)

### 测试模式
每个块大小测试执行：
1. **分配阶段：** 用 N 次分配填充批次
2. **释放阶段：** 释放所有 N 次分配
3. **重复：** 迭代直到完成 1000 万次总操作

### 公平性控制
- 所有分配器执行相同的操作数
- 预热迭代以填充缓存（隐含在批次循环中）
- 顺序执行以避免温度限制
- 每个块大小测试使用全新的分配器实例

### 测量精度
- 计时仅包括分配/释放操作
- 分配器初始化排除在测量之外
- 批次指针数组预先分配
- 结果为**挂钟时间**（包含系统开销）
